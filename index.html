자기소개 · About Me

데이터 분석과 웹 서비스를 함께 공부하는 경영정보학과 학생입니다.

안녕하세요, 솔담대학교 경영정보학과에 재학 중인 윤서하입니다. 경영 현장에서 발생하는 문제를 데이터로 읽어내고, 이를 서비스와 의사결정으로 연결하는 과정에 관심이 많습니다. 대학에서는 SQL과 통계 분석을 기반으로 실제 데이터를 정제하고 시각화하는 프로젝트를 진행해 왔으며, 웹 페이지 구축과 데이터베이스 설계 역할도 함께 맡아 왔습니다.

여울 데이터랩 인턴십에서 영업 데이터 대시보드를 구축한 경험을 바탕으로, 앞으로는 데이터 기반 경영 의사결정을 지원하는 서비스 기획과 분석 업무에 기여하고 싶습니다. 꾸준히 배우고 협업하는 자세로 새로운 도메인의 데이터에 빠르게 적응하겠습니다.
